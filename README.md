# Python Wheel of Fortune

A simple command-line Wheel of Fortune program built with Python.

The program allows users to choose between 2 and 10 segments, enter an option for each segment, and randomly select one option.

## Features

 Supports 2 to 10 segments
 User-defined options
 Randomly selects one option
 Simple command-line interface
 Uses Python's `random` module

## Technologies

 Python
 Random module
 Command Line / Terminal
